### 🖋 尘墨工坊 · Chenmo Studio

- **在线体验**：<https://chenmo-studio.app.workbuddy.host/>
- **源码**：私有仓库维护中（个人数据类应用，源码含部署配置，暂不公开）
- **技术栈**：原生 HTML/CSS/JS · CloudBase 云函数 · 文档型数据库
- **亮点**：浏览器本地不落任何业务数据；免费套餐月用量占比约 1%；附带到期自动续费守护脚本
